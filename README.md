# homebrew-watasu

Dedicated Homebrew tap for the `watasu` CLI.

## Install

```bash
brew install watasuio/watasu/watasu
```

The fully qualified name trusts only the Watasu formula. See
[Homebrew tap trust](https://docs.brew.sh/Tap-Trust).

## Update

```bash
brew upgrade watasuio/watasu/watasu
```

If an existing installation reports the formula as untrusted, run
`brew trust --formula watasuio/watasu/watasu` and retry the upgrade.

## Maintenance

This tap provides the Homebrew formula for installing and updating `watasu`.
